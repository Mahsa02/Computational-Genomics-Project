# Spatial Transcriptomics — Cellpose + Cosine Prototype Pipeline

Segments cells in Xenium spatial transcriptomics data (human pancreas) using Cellpose,
then assigns each cell a biological identity by comparing its gene expression profile
against scRNA-seq-derived cell-type prototypes via cosine similarity.

## Project context

This pipeline was built as a pragmatic baseline toward a larger goal: making cell
segmentation itself biologically informed, rather than treating morphology and gene
expression as separate steps. The current approach segments first (Cellpose), then
uses prototype similarity to label and evaluate each cell. Notebook 04 implements
a post-processing step that uses similarity scores to identify and re-segment
ambiguous cells — the first step toward closing that loop.

## Key parameters and design decisions

| Notebook | Parameter | Value | Why |
|---|---|---|---|
| 01 | `CELL_TYPE_COL` | `celltype` | Column name in `pancreas.h5ad` obs |
| 01 | `exclude` set | `dropped`, `not applicable`, `co-expression`, `unclassified endocrine`, `unclear`, `unclassified` | These labels are QC artifacts or ambiguous — including them creates spurious prototypes that steal assignments from real cell types |
| 02 | `CROP_SIZE` | `512` | Centre crop in pixels |
| 02 | `CELL_DIAMETER` | `30` | Expected cell diameter for Cellpose (pixels) |
| 02 | `MICRONS_PER_PIXEL` | `0.2125` | Xenium physical pixel size — required to convert transcript coordinates (microns) to image coordinates (pixels) |
| 02 | `GENE_COL` | `feature_name` | Gene column name in `transcripts.parquet` |
| 03 | `CELL_EXPR_PATH` | `cell_expression_aligned.csv` | Output of notebook 02 — do not use `cell_expression_crop.csv` (pre-existing file with different gene set) |
| 04 | `CONFIDENCE_THRESHOLD` | `0.5` | Absolute threshold — largely informational given sparse panel |
| 04 | `MARGIN_THRESHOLD` | `0.05` | **Primary confidence metric** — gap between best and 2nd-best prototype score. More meaningful than absolute threshold for sparse gene panels |
| 04 | `RETRY_DIAMETER` | `20` | Smaller diameter used when re-segmenting low-confidence cells |

## A note on cosine similarity scores

Absolute cosine similarity scores in this pipeline are low (typically 0.2–0.5).
This is expected: the Xenium panel covers only 126 genes out of tens of thousands
in the scRNA-seq reference. With most of the signal missing, even a perfect
cell-type match will score low in absolute terms.

## Evaluation approach (notebook 04)

Because the Xenium panel does not include canonical islet markers (INS, GCG, SST),
alpha, beta, and delta cell assignments cannot be validated by marker expression.
Validation is meaningful for:
- **Ductal** — CFTR, KRT7, EHF, ANPEP, EPCAM
- **Acinar** — AMY2A, DMBT1, HMGCS2
- **Stellate/mesenchymal** — ACTA2, PDGFRB, PDGFRA, MYH11, MYLK
- **Endothelial** — PECAM1, VWF, EGFL7, RAMP2
- **Immune** — PTPRC, CD3E, CD68, GNLY, GZMB, CD8A, CD4
- **Mast** — MS4A2, FCER1A

The marker gene heatmap (section 2 of notebook 04) should show highest expression
of each marker group in its corresponding predicted cell type (diagonal pattern).

## Background

**Cellpose** is a deep learning segmentation model that predicts a flow field pointing
each pixel toward its nearest cell centre, then traces boundaries from those flows.
This handles touching and overlapping cells well without requiring manual parameter
tuning per tissue type.

**Cosine similarity** measures the angle between two gene expression vectors,
independent of their magnitude. It is the standard metric for comparing sparse,
high-dimensional expression profiles.

**The coordinate system mismatch**: Xenium transcript coordinates are in microns;
the OME-TIFF image is in pixels. These must be reconciled using the physical pixel
size (0.2125 µm/pixel) before any spatial assignment. Failing to do this results
in zero transcript assignments.
