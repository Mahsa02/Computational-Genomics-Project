# Spatial Transcriptomics: Cellpose + Cosine Prototype Pipeline

This project builds a baseline pipeline for spatial transcriptomics that combines morphology-driven segmentation (Cellpose) with gene-expression-based cell typing.

In practice, this separation breaks down: segmentation errors propagate directly into biological misclassification. We show that, under a sparse gene panel, cosine similarity produces systematically low-confidence assignments — motivating a post-processing step that uses biological signal to identify and correct segmentation failures.

## Project context

This pipeline was built as a pragmatic baseline toward a larger goal: making cell
segmentation itself biologically informed, rather than treating morphology and gene
expression as separate steps. The current approach segments first (Cellpose), then
uses prototype similarity to label and evaluate each cell. We implemented
a post-processing step that uses similarity scores to identify and re-segment
ambiguous cells — the first step toward closing that loop. Biological signal acting as feedback on morphology.

## Key findings 

* Cosine similarity scores are uniformly low (≈0.07–0.15), reflecting the limitations of sparse Xenium gene panels.
* Margin between top cell-type matches is near zero for most cells → assignments are inherently ambiguous.
* Absolute confidence thresholds fail completely (100% of cells flagged low-confidence).
* Data-driven thresholds improve interpretability but reveal that most cells remain weakly identified.
* Marker-gene validation is constrained by panel coverage, limiting biological verification.
* Post-processing (re-segmentation of low-confidence cells) yields only modest improvements, primarily in worst-case cells.

## Key parameters

| Notebook | Parameter | Value | Why |
|---|---|---|---|
| 01 | `CELL_TYPE_COL` | `cell_type` | Column name in `human_breast.h5ad` obs |
| 01 | `exclude` set | `dropped`, `not applicable`, `co-expression`, `unclassified endocrine`, `unclear`, `unclassified` | These labels are QC artifacts or ambiguous — including them creates spurious prototypes that steal assignments from real cell types |
| 02 | `CROP_SIZE` | `512` | Centre crop in pixels |
| 02 | `CELL_DIAMETER` | `30` | Expected cell diameter for Cellpose (pixels) |
| 02 | `MICRONS_PER_PIXEL` | `0.2125` | Xenium physical pixel size — required to convert transcript coordinates (microns) to image coordinates (pixels) |
| 02 | `GENE_COL` | `feature_name` | Gene column name in `transcripts.zarr` |
| 03 | `CELL_EXPR_PATH` | `cell_expression_aligned.csv` | Output of notebook 02 — do not use `cell_expression_crop.csv` (pre-existing file with different gene set) |
| 04 | `CONFIDENCE_THRESHOLD` | `0.5` | Absolute threshold — largely informational given sparse panel |
| 04 | `MARGIN_THRESHOLD` | `0.05` | **Primary confidence metric** — gap between best and 2nd-best prototype score. More meaningful than absolute threshold for sparse gene panels |
| 04 | `RETRY_DIAMETER` | `20` | Smaller diameter used when re-segmenting low-confidence cells |

## Evaluation approach
We evaluate assignments along three axes:

* Similarity metrics
    * Best cosine similarity score per cell
    * Margin between top two cell-type matches (primary confidence signal)
* Distributional diagnostics
    * Histogram of similarity scores
    * Margin distribution to quantify ambiguity
* Biological validation
    * Marker gene enrichment across predicted cell types
    * Limited by gene panel coverage (many canonical markers absent)
* Ablation experiments (Notebook 04)
    * Select low-confidence cells based on similarity/margin
    * Re-segment using alternative parameters
    * Accept refinements only if similarity improves
 
## Limitations
* Sparse gene panel
    * Many canonical markers (e.g., COL1A1, ACTA2, VWF) are absent
    * Limits both classification accuracy and biological validation
* Low signal-to-noise in similarity space
    * Cosine scores are compressed → weak separation between cell types
* Segmentation–expression mismatch
    * Errors in segmentation directly distort expression profiles


## Background

**Cellpose** is a deep learning segmentation model that predicts a flow field pointing
each pixel toward its nearest cell centre, then traces boundaries from those flows.
This handles touching and overlapping cells well without requiring manual parameter
tuning per tissue type.

**Cosine similarity** measures the angle between two gene expression vectors,
independent of their magnitude. It is the standard metric for comparing sparse,
high-dimensional expression profiles.
